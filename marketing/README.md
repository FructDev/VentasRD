## Cómo exportar cada arte como imagen

1. Abre el archivo `.html` en Chrome (doble clic).
2. Presiona **F12** → **Ctrl+Shift+P** → escribe `screenshot` → elige **"Capture full size screenshot"**.
3. Chrome descarga un PNG del tamaño exacto (1080×1920 o 1080×1080), listo para subir.
